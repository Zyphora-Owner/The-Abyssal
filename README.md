
# PROJECT ELYNDOR

### Medieval Isekai Survival Multiplayer RPG

Project Elyndor is an original 3D open-world
Medieval Fantasy Survival RPG developed
with Unreal Engine 5.

## Game Overview

- Genre: Survival, Action, RPG
- World: Seamless Open World
- Multiplayer: PvE + PvP
- Camera: Third Person
- Visual: Stylized Realistic
- Networking: Dedicated Server
- Platforms: PC, Console, Mobile

## Core Features

- Open World Exploration
- Survival Mechanics
- Character Customization
- Combat System
- Magic System
- Inventory and Crafting
- Character Progression
- Multiplayer
- NPC and Monster AI
- Dungeon and Bosses
- Building and Settlement

## Development

Current Version: Alpha 0.1

Status: Initial Development

Engine: Unreal Engine 5

Programming: C++ and Blueprint
